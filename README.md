# Vincis Partner Hub

eu conversei com outra ia e sobre o que estou querendo. Ela me passou isso: Crie um frontend completo em React + Next.js + TailwindCSS para uma plataforma SaaS premium chamada Vincis.

IMPORTANTE:

* Criar SOMENTE frontend visual
* NÃO criar backend
* NÃO criar APIs
* NÃO criar banco de dados
* NÃO implementar lógica real
* Apenas mock visual sofisticado
* Tudo em UM ÚNICO ARQUIVO
* Estrutura pronta para posteriormente separar em componentes

Objetivo:
Criar uma experiência visual extremamente moderna, premium, persuasiva e motivacional para parceiros/captadores da plataforma.
